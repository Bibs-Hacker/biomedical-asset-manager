# 📖 Overview

Managing biomedical equipment manually can easily lead to misplaced devices, delayed returns, and poor accountability.

The **Biomedical Equipment Lending System** is a modern web application developed to digitize equipment lending workflows inside hospital biomedical engineering departments.

It provides an intuitive dashboard where technicians can:

- Register borrowed equipment
- Monitor active loans
- Track overdue items
- Record returned equipment
- View lending statistics
- Improve accountability across departments

The project emphasizes **speed**, **simplicity**, and **clean user experience** while maintaining an elegant professional interface.
